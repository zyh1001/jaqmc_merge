# 固定构型下的圆盘局域能量

提交脚本对已训练的圆盘波函数进行扫描，不继续训练。默认读取四电子训练目录，
从最终检查点的构型中选择波函数幅度最大的一个，固定电子 1、2、3，
让电子 0 绕电子 1 移动。下面的命令从项目根目录运行。

```bash
bash scripts/analyze_disk_local_energy.sh --dry-run
sbatch scripts/analyze_disk_local_energy.sh
```

终端参数可以指定训练目录、检查点、输出目录和网格。输出目录必须为空。

```bash
sbatch scripts/analyze_disk_local_energy.sh --run-dir /absolute/training/path --checkpoint /absolute/checkpoint.npz --output /absolute/new/output --angles 64 --radial-points 200 --batch-size 16
```

默认在 $10^{-4}\le r\le3$ 使用 200 个对数分布半径，之后以不超过 0.2 的间隔
延伸至绕行中心到原点距离加 14。先使用 64 个角度，再使用 128 个角度复算，
并在相邻半径的几何中点增加计算。每个半径按波函数模平方对角度加权。
主图展示完整体系总局域能量、动能、势能的实部，另有 $r\le1$ 的小距离图。
全部角度的坐标、复数局域能量、动能及势能分量保存在原始数据文件中。

固定其余电子只限制扫描位置，动能仍对全部电子坐标求导。
势能包含全部电子对的库仑相互作用以及全部电子与正电背景的作用，沿用训练时的
背景半径和不计背景自能常数的约定。长度单位为磁长度，能量单位为磁回旋能量。
这些曲线是一个固定构型下的条件结果，不是整个体系的能量期望值。

计算严格匹配保存参数的名称与形状，将保存的单精度参数转换为双精度。
这种转换不能恢复训练时未保存的精度。程序检查四电子高斯波函数的总动能为 2，
并检查可解析的角度加权平均以及每个点的能量分量加和关系。
非有限结果会停止作业并保存出错位置，不会被丢弃。

角度加密检查和径向中点检查对每个分量分别使用绝对容差和相对容差，默认均为
$10^{-3}$。未通过的位置保存在两个检查表中，并在图片上标明。
径向中点检查比较实际中点值与端点在对数距离上的线性插值，衡量曲线的采样密度，
不能证明波函数导数本身已经准确。完整结果与来源校验值保存在结果目录。

```bash

```
